# APM1220 Summative Assessment 1: Wine Quality Analysis

**Course:** APM1220 — Applied Multivariate Data Analysis

**Assessment:** Summative Assessment 1

**Methods:** Exploratory Data Analysis (EDA), Multivariate Analysis of Variance (MANOVA), Principal Component Analysis (PCA), and Exploratory Factor Analysis (EFA).

## Project Description

This project examines the physicochemical properties of red and white Vinho Verde wines using the UCI Wine Quality Dataset. The analysis explores differences between wine types and investigates relationships among the measured chemical variables using multivariate statistical methods.

## Dataset

The repository includes two datasets from the UCI Machine Learning Repository:

- `winequality-red.csv` — red wine observations.
- `winequality-white.csv` — white wine observations.

Source: Cortez, P., Cerdeira, A., Almeida, F., Matos, T., & Reis, J. (2009). *Modeling wine preferences by data mining from physicochemical properties*. Decision Support Systems, 47(4), 547–553. https://doi.org/10.1016/j.dss.2009.05.016

Dataset: https://doi.org/10.24432/C56S3T

## Repository Contents

- `SA1_Wine_Quality_Report.pdf` — final statistical report.
- `SA1_Wine_Analysis.py` — Python analysis script.
- `winequality-red.csv` — red wine dataset.
- `winequality-white.csv` — white wine dataset.
- `output/` — analysis figures, tables, and numerical results generated by the script.

## Analysis Overview

The Python script performs data preparation and exploratory analysis, evaluates differences between red and white wines using MANOVA, summarizes the physicochemical variables using PCA, and explores latent factor structure using EFA.

## Reproducibility

The analysis uses Python and scientific-computing libraries. Refer to the analysis script for the required packages and execution instructions. The generated outputs should be included in the repository to support the reported findings.
